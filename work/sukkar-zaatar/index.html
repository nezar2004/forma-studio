E-commerce · Bakery management · Academic project

Sukkar & Zaatar ✳

A warm, premium storefront for a fictional Jordanian bakery, with a complete PHP/MySQL app developed for the BIT481 Web Application Development 2 assignment at Yarmouk University.

Launch interactive preview ↗Explore other work

The linked preview demonstrates the storefront design and temporary bag interactions. Real account management, orders, admin tools, and database operations require running the separate PHP/MySQL application on a compatible server.

Customer experience

Product catalogue, filters, product details, shopping bag, checkout, orders, contact, and customer accounts.

Business operations

Admin dashboard, product CRUD, order status tracking, inventory, and a normalized MySQL schema with secure PHP queries.

Technology

HTML, CSS, JavaScript, PHP, MySQL, responsive UI, PDO prepared statements, CSRF checks, and session-based authentication.

Project status

Academic prototype. Static preview hosted on GitHub Pages; full database-backed deployment is not yet available publicly.
